- Boy: `kucuk` / `orta` / `buyuk` — makine karşılığı yarım-makine **tam sayı birim**: 1 / 2 / 4.
- Ekler: `yorgan`, `battaniye`; varyant `tek` / `cift`; adet. Her ek **2 birim** (1 makine).
- Renk ayrımı standart, fiyata gömülü; müşteri UI’da renk sorusu yok. Kapıda `color_groups` (1–3) yalnız kayıt.
- **D-033:** `MIN_ORDER` yok; platform min/max aralığı dışı sağlayıcı fiyatı reddedilir.
- Kapıda `confirmed_size` + ek adetleri + foto; büyük boy/fazla ek → `price_change` müşteri onayı. Red → `cancel_reason=size_rejected`, ücretsiz iptal.
