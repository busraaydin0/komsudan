# Komşudan

Çukurambar pilotu. Çamaşırı kapıda veya nötr noktada bırak, katlanmış al. Eve kimse girmez.

Harita: **2D / 3D**. Pinler hizmet veren komşular, kesik kareler nötr teslim noktaları.

```bash
npm install
npm run dev
```

`/` müşteri haritası · `/hizmet` hizmet veren masası. Siparişler bu tarayıcıda tutulur; ödeme simülasyon.
